# 🧠 OmniBrain — AI-Powered Document Q&A

OmniBrain is a production-ready backend that lets you upload PDFs and ask
natural-language questions about their content. It uses **LangGraph**,
**Google Gemini**, and **ChromaDB** to deliver accurate answers with
source citations.

---

## ✨ Features

- 📄 **PDF Upload** — Drag-and-drop PDFs; text extraction + OCR fallback
- 🔍 **Semantic Search** — Sentence-BERT embeddings + ChromaDB vector search
- 🤖 **AI Q&A** — LangGraph workflow orchestrates Gemini for RAG answers
- 📊 **Analytics** — Per-document stats, dataset summaries, similarity analysis
- 🔌 **REST API** — Clean FastAPI endpoints ready for any frontend (React, etc.)
- 🧱 **Clean Architecture** — SOLID principles, dependency injection, separation of concerns
